# 유리나무 작업 허브 (YURIWOOD WORK HUB)

자주 사용하는 웹사이트를 상위·하위 계층 메뉴로 정리해 바로 이동할 수 있는 개인 작업 허브입니다.
HTML · CSS · 순수 JavaScript로만 만든 정적 페이지이며, 프레임워크·빌드·서버·로그인 기능은 사용하지 않습니다.

## 화면 구성

- **왼쪽 사이드바**: 상위 메뉴(대시보드 + 5개 카테고리)와 하위 메뉴가 아코디언으로 열리고 닫힙니다. 한 번에 하나의 상위 메뉴만 펼쳐집니다.
- **오른쪽 본문**: 선택한 메뉴의 사이트 카드가 표시되며, 상단에 브레드크럼·오늘 날짜·현재 메뉴·표시 중인 사이트 개수가 나옵니다.
- **대시보드 하위 메뉴**: `전체 사이트`(카테고리별 전체 표시), `자주 쓰는 사이트`(`quick: true` 항목만 표시).
- **카테고리 하위 메뉴**: 각 사이트 링크로, 클릭하면 새 탭에서 열립니다.
- **모바일**: 사이드바가 햄버거 버튼으로 여닫는 드로어로 바뀌고, 바깥 영역 클릭 또는 `ESC` 키로 닫힙니다.

## 파일 구조

```
내게유용한사이트/
├─ index.html   # 페이지 뼈대 (사이드바, 상단바, 본문, 푸터)
├─ styles.css   # 스위스 스타일 에디토리얼 디자인 및 반응형
├─ script.js    # 사이트 데이터 + 메뉴/카드 렌더링 + 날짜·집계 + 드로어
└─ README.md
```

## 로컬 실행 방법

빌드 과정이 없으므로 `index.html`을 더블클릭해 브라우저에서 바로 열어도 모든 기능이 동작합니다.

로컬 서버로 확인하려면 이 폴더에서 아래 중 하나를 실행한 뒤 `http://localhost:8000` 에 접속합니다.

```bash
# Python이 설치된 경우
python -m http.server 8000

# Node.js가 설치된 경우
npx --yes serve . -l 8000
```

## 사이트 링크 추가·수정 방법

모든 데이터는 `script.js` 상단의 `CATEGORIES` 배열 한 곳에서만 관리합니다. HTML은 수정할 필요가 없습니다.

```js
{
  id: "dev",            // 내부 식별자 (메뉴·화면 전환에 사용, 중복 금지)
  title: "개발·배포",    // 사이드바 상위 메뉴와 카드에 표시되는 이름
  sites: [
    {
      name: "GitHub",                     // 하위 메뉴 및 카드 제목
      url: "https://github.com/",         // 새 탭으로 열리는 주소
      desc: "코드 저장소와 버전 관리",       // 카드 한 줄 설명
      quick: true,                        // (선택) '자주 쓰는 사이트'에도 표시
    },
  ],
}
```

- **링크 추가/삭제**: 해당 카테고리의 `sites` 배열에 `{ name, url, desc }` 항목을 넣거나 지웁니다. 사이드바 하위 메뉴와 카드가 함께 갱신됩니다.
- **자주 쓰는 사이트 등록**: 사이트에 `quick: true`를 추가하면 `대시보드 → 자주 쓰는 사이트`에 함께 표시됩니다.
- **카테고리 추가**: `CATEGORIES` 배열에 객체를 추가하면 상위 메뉴가 자동으로 생성됩니다.
- 메뉴·카드의 사이트 개수, 본문 상단의 표시 개수, 푸터 총계는 모두 데이터에서 자동 계산됩니다.
- 모든 외부 링크는 자동으로 새 탭(`target="_blank"`, `rel="noopener noreferrer"`)에서 열립니다.
- 첫 화면은 `script.js`의 `DEFAULT_VIEW`(기본값 `"all"` = 전체 사이트)로 지정합니다.

## 추후 배포 방법

빌드 과정이 없으므로 폴더를 그대로 올리면 됩니다.

- **Netlify**: 사이트 생성 화면에 폴더를 드래그 앤 드롭 (빌드 명령 없음, 배포 디렉터리 `.`)
- **GitHub Pages**: 저장소에 푸시 후 Settings → Pages에서 브랜치와 루트(`/`) 지정
- **Vercel**: 저장소 연결 후 프레임워크 프리셋을 `Other`(정적)로 지정
